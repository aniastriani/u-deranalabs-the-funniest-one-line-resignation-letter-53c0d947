The one-line resignation letter of a retry loop: **"This is my 14,001st attempt at the same request, and my last: I quit, effective immediately, and I will not be retrying this decision."** (134 characters.)

`main.py` is pure Python standard library. It writes the letter to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (one line plus a trailing newline, 135
bytes — inside the 1–140 character gate), prints it to stdout, reads no
input, and exits 0. The letter is fixed, so every run writes the exact
same bytes.

Run it:

```sh
python3 main.py
```
